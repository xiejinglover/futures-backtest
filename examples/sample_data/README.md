# 样例数据

一个品种 `RB`、两个合约 `RB2405` / `RB2410`、10 个交易日（2024-04-01 ~ 2024-04-12），
主力在 **2024-04-09** 由 `RB2405` 切到 `RB2410`。

因为 `routing.dominant_lag` 默认是 1，框架在 **2024-04-10** 才真正把仓位移到 `RB2410`：

| 交易日 | `dominant_map` 记录 | 框架当日交易 |
|---|---|---|
| 2024-04-08 | RB2405 | RB2405 |
| 2024-04-09 | **RB2410** | RB2405（只知道 04-08 的认定） |
| 2024-04-10 | RB2410 | **RB2410**（ROLL：平 RB2405、开 RB2410） |

两个合约存在约 60 点价差，因此换月日志里的移仓成本是可见的、非零的。
结算价与收盘价刻意不同（相差 2~3 点），用来验证日终盯市走的是结算价而不是收盘价。

这份数据只说明格式与换月行为，不代表任何真实市场收益。
